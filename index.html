ANSLUTNING & SÄKERHET

Inställningar

Anslut till din Homey Pro över hemnätverkets Wi-Fi.

Anslut ditt hem

Du hittar IP-adressen i Homey Web App under Inställningar → Allmänt → Systeminformation.

Nyckeln skickas enbart direkt till den Homey-adress du anger. Om du väljer att spara nyckeln lagras den i webbläsaren på enheten, inte på någon server. Undvik det på delade enheter.

Så här ansluter du

  1. Anslut iPhone/iPad till samma Wi-Fi som din Homey Pro.
  2. Öppna my.homey.app på din dator.
  3. Skapa en ny API-nyckel under Inställningar → API Keys med rättigheter att läsa och styra enheter, läsa och starta Flows samt hantera ljusscener.
  4. Fyll i Homeys IP och nyckeln till vänster. Tryck Testa anslutning.
Viktigt om webbappar

Safari kan blockera anrop till Homey av säkerhetsskäl (CORS/åtkomst till lokala nätverk), även när IP och nyckel är rätt. Då behövs en annan anslutningslösning. Appen visar ett felmeddelande i stället för att gissa.
